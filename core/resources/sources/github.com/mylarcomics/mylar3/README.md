# Mylar3

Automated comic book downloader (*arr family). Runs the LinuxServer.io image
`linuxserver/mylar3:v0.11.0-ls273` instead of the repository's Dockerfile, which
no longer builds.

- `/config` (config.ini, mylar.db) and `/comics` are named volumes.
- The login is generated by the engine (`credentials:` in `panelalpha.yaml`)
  and returned by `GET /projects/{name}/app-credentials` (MCP
  `app_credentials_get`); the API key is generated once into
  `~/.panelalpha/mylar/app.env`. Both are seeded into `config.ini` on the first
  boot only; the API key is shown in Settings.
- No ComicVine API key is set; add one under Settings before searching.
