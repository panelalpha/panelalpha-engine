# pgAdmin 4 (github.com/pgadmin-org/pgadmin4)

Web administration tool for PostgreSQL (Flask/gunicorn, SQLite config DB).

## Deploying

Deploy as is. The initial admin login (`PGADMIN_DEFAULT_EMAIL`,
`PGADMIN_DEFAULT_PASSWORD`) is generated by the engine: read it with
`GET /projects/{name}/app-credentials` (MCP `app_credentials_get`). The email is
the project's own, or an address on the site's domain without one. Project env
vars with those names, set before the first deploy, are used instead; pgAdmin
rejects an email on a special-use domain such as `.local`. They are read only
when `pgadmin4.db` is first created.

## What the recipe does

- `overrides/docker-compose.yml` runs `dpage/pgadmin4:9.18` on port 8080
  (`PGADMIN_LISTEN_PORT`) with `/var/lib/pgadmin` on the named volume
  `pgadmin-data`, kept across redeploys.
- The login reaches the app through
  `env_file: ../.panelalpha/app-credentials.env`. `ready` makes `compose up -d`
  wait for `/misc/ping`.
- The repository's own Dockerfile is not built: its webpack step ran out of
  memory in a 2000 MB account.
