# Bugzilla (github.com/bugzilla/bugzilla)

Bug tracker: Perl/mod_perl under Apache on :80, MariaDB beside it. Built from
the repository's own `Dockerfile` and `Dockerfile.mariadb` (default branch 5.2,
the stable release branch).

## Deploying

Optional project environment variables, read on the first deploy only
(checksetup.pl creates the admin once):

- `BZ_ADMIN_EMAIL` (default `admin@bugzilla.test`)
- `BZ_ADMIN_PASSWORD` (default `password01!`, upstream's compose default)
- `BZ_ADMIN_REALNAME` (default `Administrator`)

## What the recipe does

- `overrides/docker-compose.yml` replaces upstream's compose: no `.:/mnt/sync`
  bind mount, `command: /root/docker/startup.sh` (the Dockerfile's own CMD
  points at a path it deletes), `BZ_URLBASE` from the public URL, DB and
  MariaDB root passwords generated by the engine per account, `data/` and
  MariaDB on named volumes, and a `ready` gate on `index.cgi` answering 200.
- `files/.dockerignore` keeps `.env` and `.git` out of the image: the
  Dockerfile copies the context into the docroot.
