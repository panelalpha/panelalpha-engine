# Spliit (github.com/spliit-app/spliit)

Expense sharing between friends (Splitwise alternative). One Next.js server on
:3000 with PostgreSQL.

## Deploying

No variables are required. The site opens Spliit's home page; groups are
created from there and shared by link (Spliit has no user accounts). Optional
features (S3 expense documents, OpenAI receipt scanning, analytics,
`DEFAULT_CURRENCY_CODE`) take the upstream env vars from the README.

## What the recipe does

- `overrides/docker-compose.yml` replaces the repository's `compose.yaml`
  (a source build whose `next build` is OOM-killed in a 2 GB account) with the
  published `ghcr.io/spliit-app/spliit:1.28.0` image and `postgres:17-alpine`.
- `BASE_URL` is the site's address; the DB password is `${POSTGRES_PASSWORD:?}`,
  generated by the engine per account and stable across redeploys.
- The container runs `prisma migrate deploy` on start. A `ready` gate waits for
  `/api/health/readiness` (checks the database too).
- Data: `db_data` named volume (PostgreSQL); `next_cache` for Next's image cache.
